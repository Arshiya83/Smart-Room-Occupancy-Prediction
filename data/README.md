# Dataset

This project uses the UCI Occupancy Detection dataset.

## Dataset Source

UCI Machine Learning Repository:

https://archive.ics.uci.edu/dataset/357/occupancy-detection

The dataset contains environmental sensor measurements used to predict whether a room is occupied or unoccupied.

## Features

- Temperature
- Humidity
- Light
- CO2
- HumidityRatio

## Target

- 0 - Unoccupied
- 1 - Occupied
